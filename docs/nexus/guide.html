BODYCAM MAP IMPORTER

Add custom maps to Bodycam. Each map gets its own card in Play > Custom.

The app with Prison V2P installed.

INSTALL A MAP (4 STEPS)

  1. Close Bodycam.
  2. Start BodycamMapInstaller.exe. It finds Bodycam through Steam by itself.
    Windows may say "Windows protected your PC" (new apps without a paid signature always get this): click More info > Run anyway.
  3. Drag the map you downloaded (.bcmap, .zip or .pak) onto the window.
  4. Bodycam > Play > Custom > pick a mode > the map > host a private match and add bots.
Remove a map: select it, click DELETE.  Playing online: click "Hide custom maps" first, "Show custom maps again" after.
Nothing is ever deleted: every replaced file goes to Bodycam\Content\Paks\_backup\.

MAKE YOUR OWN MAP

Maps are built in Unreal Engine 5.5 with the Bodycam Map Kit: a ready Unreal project with the game's mode templates and one command that checks your level, builds all 7 modes (Hardpoint, Team Deathmatch, Deathmatch, Versus, Gun Game, Body Bomb, Wingman), bakes the bot navigation, makes the menu card from your screenshot, cooks and packs it. Bought or downloaded assets work too, with their own materials and shaders.

  1. Install Unreal Engine 5.5, Git for Windows and Python 3.
  2. Build your level, add team spawns and (for Hardpoint) a hardpoint zone.
  3. Run newmap.sh MyMap "My Map" photo.png 0.1.0
  4. Share the .bcmap it makes. Players drop it on this app.

The Map Kit download is being cleaned for public release. Full step-by-step guide: the GitHub link under the download.
